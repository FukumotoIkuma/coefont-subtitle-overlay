# CoeFont Subtitle Overlay

CoeFont通訳のタブを画面共有で取り込み、字幕部分だけを切り抜いて、常に最前面の小窓(動画Picture-in-Picture)に出す単一HTML。
ビルドなし・サーバー処理なし・映像はブラウザ外に出ない。発表ソフト側の設定は何も変えない。

## 起動

Chrome / Edge で次のURLを開くだけ(インストール不要):

https://fukumotoikuma.github.io/coefont-subtitle-overlay/

`main` ブランチの `index.html` が GitHub Pages でそのまま配信される。別の場所に置く場合も、HTTPS の静的ホスティングに `index.html` を置くだけでよい。
配信は10分キャッシュされる。画面右下の「配信日時」で読み込んでいる版を確認できる。

## 画面構成

| 場所 | 役割 |
|---|---|
| 入力: CoeFont(左上) | 取り込んだ CoeFont の画面。ドラッグで字幕の範囲を囲む |
| 聴衆側の画面(右上) | 背景を透過するときだけ使う。取り込んだスライドの上に、小窓を置く場所を赤枠で決める |
| ソース | 字幕(CoeFont のタブ)と、透過用のスライド(任意)の選択・変更・停止 |
| 字幕の見た目 | 背景の透過(白地/黒地を抜く)、不透明度、初期化 |
| 出力 | 字幕の小窓を出す |

設定は localStorage に保存され次回復元される。共有が切れたらソースの「選択」を押し直すだけで、小窓は開いたままでよい。本ツールのタブを閉じると小窓も閉じる。

## 使い方

1. CoeFont の招待URLを別タブで開いて参加し、「CoeFont のタブを選択」で取り込む
2. 左で字幕の範囲を囲む
3. 「字幕の小窓を出す」を押し、小窓を聴衆側ディスプレイへドラッグして位置と大きさを決める
4. 発表ソフトでスライドショーを通常どおり開始する

### 背景を透過して見せる(任意)

小窓そのものは透過できない。代わりに、小窓の真裏にあるスライドの部分を小窓の中に下地として描き、その上に字幕を合成することで透けて見せる。

1. スライドショーを開始してから「スライドショーのウィンドウを選択」で**ウィンドウ**を選ぶ(画面全体は選ばない)
2. 「背景の透過」で、CoeFont の字幕が白地なら「白地を抜く」、黒地なら「黒地を抜く」を選ぶ
3. 右の赤枠を、小窓を置きたい場所に合わせる
4. 聴衆側ディスプレイで、小窓を赤枠と同じ位置・大きさに置く。継ぎ目がずれて見えたら赤枠のほうを動かして合わせる

ページから小窓の位置は取得できないため、位置合わせは目視になる。下地が単色に近いスライドでは多少ずれても目立たない。

## 対応環境

デスクトップ版 Chrome / Edge のみ。映像の合成(Insertable Streams)と動画PiPが必要で、Firefox / Safari では理由を表示して停止する。

## 出力を動画PiPに限っている理由

- 通常のブラウザ窓(全画面表示を含む): タブを共有している間、Chrome の「〜を共有しています」バーが出て聴衆に見える
- Document PiP: 上部にURLの帯が出て、ページ側から消せない
- 動画PiP: どちらも出ない。代わりに縦横比は切り抜き範囲に固定され、高さに下限(約146px)があり、全画面にはできない

## 未検証・既知の制約

- **全画面スライドショーの上に小窓が出るか**は OS × 発表ソフト × ディスプレイ構成に依存する。本番環境で必ず事前確認すること
- 小窓の位置はAPIから指定も取得もできない。聴衆側ディスプレイへは手でドラッグして移動する
- 小窓にマウスを載せている間は、ブラウザ標準の操作ボタンが重なって表示される
- CoeFont のタブを最小化したウィンドウに置くと映像が止まることがある。別ウィンドウに出して裏に回すのが安全
- 透過時、小窓の中のスライド部分は映像経由なので、アニメーション中は周囲よりわずかに遅れる
