# CoeFont Subtitle Overlay

CoeFont通訳のタブを画面共有で取り込み、字幕部分だけを切り抜いて常に最前面の小窓(Document Picture-in-Picture)に出す単一HTML。
ビルドなし・サーバー処理なし・映像はブラウザ外に出ない。

## 起動

Chrome / Edge で次のURLを開くだけ(インストール不要):

https://fukumotoikuma.github.io/coefont-subtitle-overlay/

`main` ブランチの `index.html` が GitHub Pages でそのまま配信される。別の場所に置く場合も、HTTPS の静的ホスティングに `index.html` を置くだけでよい。

## 使い方

1. CoeFont の招待URLを別タブで開いて参加する
2. 本ツールで「① 字幕画面を選択」→ CoeFont のタブを選ぶ
3. プレビュー上をドラッグ(またはスライダー)で字幕領域を囲む
4. 「② 字幕を表示」で小窓を開き、位置とサイズをドラッグで調整
5. スライドショーを開始

- 「枠なし」ON(既定): 動画PiPで表示。URLの帯が出ず、小窓の縦横比は切り抜き範囲に固定される
- 「枠なし」OFF: Document PiPで表示。上部にURLの帯が出る(ブラウザの仕様で消せない)が、縦横比は自由で余白は背景色で埋まる
- 切り抜き範囲と背景色は localStorage に保存され次回復元される
- 共有が切れたら「① 字幕画面を選択」を押し直すだけ(小窓は開いたままでよい)
- 本ツールのタブは閉じないこと(閉じると小窓も閉じる)

## 合成表示(スライドに字幕を重ねて全画面で出す)

小窓ではなく、スライドと字幕を1枚の画面に合成して聴衆側に出すモード。字幕の背景を抜ける・位置と大きさを固定できる・URLの帯や最小サイズの制約がない。発表ソフト側の設定は変えない(発表者ツールもそのまま)。

1. ①で CoeFont のタブを選び、字幕領域を調整する
2. 発表ソフトでスライドショーを通常どおり開始する(聴衆側に全画面、手元に発表者ツール)
3. 「③ スライドショーのウィンドウを選択」でスライドショーの**ウィンドウ**を選ぶ(画面全体は選ばない)
4. 「④ 合成画面を開く」で出た窓を聴衆側ディスプレイへ移動し、クリックで全画面にする
5. 手元の発表者ツールをクリックして操作を発表ソフトへ戻す

合成画面は聴衆側でスライドショーの上にかぶさり、その下にあるスライドショーを映像として映す。字幕の幅・位置・透過は手元のタブから調整する。

## 対応環境

| | 表示方法 |
|---|---|
| デスクトップ版 Chrome / Edge | Document PiP(常に最前面) |
| Firefox / Safari | 通常のポップアップ(最前面にならない。実用は厳しい) |

## 未検証・既知の制約

- **全画面スライドショーの上に小窓が出るか**は OS × 発表ソフト × ディスプレイ構成に依存する。本番環境で必ず事前確認すること
- 小窓の位置はAPIから指定できない。聴衆側ディスプレイへは手でドラッグして移動する
- CoeFont のタブを最小化したウィンドウに置くと映像が止まることがある。別ウィンドウに出して裏に回すのが安全
- 小窓方式は映像の矩形切り抜きなので背景は透過しない(透過は合成表示のみ)
- 合成表示は、発表ソフトを操作したときにスライドショーが合成画面より手前に出てくる環境だと字幕が隠れる(その場合もスライド自体は聴衆に見える)。本番機で要確認
- 合成表示のスライドは映像経由になるため、わずかな遅延と画質低下がある
