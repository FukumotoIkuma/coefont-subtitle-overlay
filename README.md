# CoeFont Subtitle Overlay

CoeFont通訳のタブを画面共有で取り込み、字幕部分だけを切り抜いて常に最前面の小窓(Document Picture-in-Picture)に出す単一HTML。
ビルドなし・サーバー処理なし・映像はブラウザ外に出ない。

## 起動

Chrome / Edge で次のURLを開くだけ(インストール不要):

https://fukumotoikuma.github.io/coefont-subtitle-overlay/

`main` ブランチの `index.html` が GitHub Pages でそのまま配信される。別の場所に置く場合も、HTTPS の静的ホスティングに `index.html` を置くだけでよい。

## 画面構成

OBS に近い作り。上段に入力と出力プレビュー、下段にソース・字幕の見た目・出力の3パネル。

| 場所 | 役割 |
|---|---|
| 入力: CoeFont(左上) | 取り込んだ CoeFont の画面。ドラッグで字幕の範囲を囲む |
| 出力プレビュー(右上) | 聴衆に見える画面そのもの。字幕をドラッグで移動、角で拡大縮小 |
| ソース | 字幕(CoeFont のタブ)とスライド(スライドショーのウィンドウ)の選択・変更・停止 |
| 字幕の見た目 | 背景の透過(白地/黒地を抜く)、不透明度、初期化 |
| 出力 | 聴衆用の全画面出力、または字幕だけの小窓 |

設定(切り抜き・配置・見た目)は localStorage に保存され次回復元される。共有が切れたらソースの「選択」を押し直すだけで、出力の窓は開いたままでよい。本ツールのタブを閉じると出力も閉じる。

## 使い方A: 全画面出力(スライド+字幕を合成)

字幕の背景を抜ける・位置と大きさを固定できる。発表ソフト側の設定は変えない(発表者ツールもそのまま)。

1. CoeFont の招待URLを別タブで開いて参加し、「CoeFont のタブを選択」で取り込む
2. 左で字幕の範囲を囲む
3. 発表ソフトでスライドショーを通常どおり開始する(聴衆側に全画面、手元に発表者ツール)
4. 「スライドショーのウィンドウを選択」でスライドショーの**ウィンドウ**を選ぶ(画面全体は選ばない)
5. 右のプレビューで字幕の位置と大きさを決める
6. 「聴衆用の全画面出力を開く」で出た窓を聴衆側ディスプレイへ移動し、クリックで全画面にする
7. 手元の発表者ツールをクリックして操作を発表ソフトへ戻す

全画面出力は聴衆側でスライドショーの上にかぶさり、その下にあるスライドショーを映像として映す。

## 使い方B: 字幕だけの小窓

スライドは取り込まず、常に最前面の小窓(PiP)を聴衆側ディスプレイに置く。手順は上の1〜2のあと「字幕だけを小窓で出す」。

- 「URLの帯を出さない」ON(既定): 動画PiP。帯は出ないが、縦横比は切り抜き範囲に固定され、高さに下限がある
- OFF: Document PiP。上部にURLの帯が出る(ブラウザの仕様で消せない)が、細い帯にできる
- 小窓は背景を透過できない

## 対応環境

| | 表示方法 |
|---|---|
| デスクトップ版 Chrome / Edge | Document PiP(常に最前面) |
| Firefox / Safari | 通常のポップアップ(最前面にならない。実用は厳しい) |

## 未検証・既知の制約

- **全画面スライドショーの上に小窓が出るか**は OS × 発表ソフト × ディスプレイ構成に依存する。本番環境で必ず事前確認すること
- 小窓の位置はAPIから指定できない。聴衆側ディスプレイへは手でドラッグして移動する
- CoeFont のタブを最小化したウィンドウに置くと映像が止まることがある。別ウィンドウに出して裏に回すのが安全
- 全画面出力は、発表ソフトを操作したときにスライドショーが出力の窓より手前に出てくる環境だと字幕が隠れる(その場合もスライド自体は聴衆に見える)。本番機で要確認
- 全画面出力のスライドは映像経由になるため、わずかな遅延と画質低下がある
